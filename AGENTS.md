## Project rules
- Data is local-first in localStorage via `src/lib/storage.ts` (no login/cloud) — the user wants a device-only first version.
- Each agreement mode has its own independent catalog; never share or fall back between rulesets — values come from different official books.
- Available import modes and project mode choices use `src/lib/agreement-phase.ts`; existing agreements retain their original mode to prevent cross-catalog conversion.
- Invented sample rows must be flagged `isTest`; user-approved workbook data is kept verbatim with provenance and imported explicitly per mode, excluding review-marked or unclear values without inventing book codes. Imports merge by mode-specific internal IDs and do not alter saved project lines.
- Service worker is generated by vite-plugin-pwa and registered only through `src/lib/pwa.ts` (guarded off in dev/preview/iframes).
