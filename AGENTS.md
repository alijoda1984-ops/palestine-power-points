## Project rules
- Data is local-first in localStorage via `src/lib/storage.ts` (no login/cloud) — the user wants a device-only first version.
- Each agreement mode has its own independent catalog; never share or fall back between rulesets — values come from different official books.
- Never ship invented point values as official; built-in rows must be flagged `isTest` and shown as test data.
- Service worker is generated by vite-plugin-pwa and registered only through `src/lib/pwa.ts` (guarded off in dev/preview/iframes).

- Reuse ProjectList for home and saved-project pages, and WorkLineForm for editable lines/catalog entries, so phone validation and labels stay consistent.
- New-project forms keep their initialized mode; editing existing projects preserves their stored mode, so older independent rulesets remain intact.
- Backup imports must roll back local storage changes on failure; project saves must refuse to overwrite unreadable existing project data.
